### Poznámka k přesnému `npm run verify`

Příkaz byl spuštěn. Lint, TypeScript a nový přímý test prošly. Výchozí Turbopack build se v izolovaném worktree zastavil pouze proto, že lokální `node_modules` je sdílený junction vedoucí mimo kořen worktree. Následný produkční build stejného kódu přes Webpack prošel. V GitHub/Vercel prostředí se závislostmi nainstalovanými přímo v projektu je nutné před produkčním nasazením potvrdit standardní build.

## Produkční postup a rollback

1. Ověřit aktuální Vercel usage a správný projekt/doménu.
2. Zkontrolovat finální diff a čistý stav release větve.
3. Vyžádat výslovný pokyn pro push větve do `Ikaros277/naturchem-web`, sloučení do `main` a jeden produkční deployment.
4. Po úspěšném standardním buildu Vercelu zopakovat smoke test proti `https://www.naturchem.cz` a neodesílat falešnou poptávku.
5. Při regresi revertovat integrační commity a jedním rollback deploymentem obnovit commit `599f7a8`.
