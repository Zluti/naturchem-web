## Ověření release kandidáta

- ESLint: 0 chyb; 17 již existujících upozornění mimo rozsah release.
- TypeScript: bez chyb, kontrola běží deterministicky s vypnutým incremental zápisem.
- Přímý test předvyplnění kontaktu: prošel pro `Provozní řády`, produktovou kategorii, lokalizovanou zprávu i omezení délky na 1 000 znaků.
- Cache-budget test: žádná route v `src/app` nesmí používat číselný interval `revalidate`; klíčové publikační route musí mít `revalidate = false`.
- Produkční Webpack build: úspěšný; vygenerováno 558 statických stránek.
- Build přehled neobsahuje u homepage, Poradny, článků ani sitemap žádné sloupce `Revalidate` nebo `Expire`.
- URL smoke test: 499 URL ze sitemap a 211 dalších interních odkazů, 0 selhání.
- Routing/SEO/API smoke test: 0 selhání; ověřeny statusy, redirecty, canonical, `hreflang`, jazyk HTML, assety, 404 `noindex`, kotva formuláře a validační odpovědi kontaktního API bez odeslání poptávky.
- Vizuální kontrola homepage: desktop 1 440 × 900 px a mobil 390 × 844 px, bez horizontálního přetečení; klíčové nadpisy a CTA jsou čitelné a spodní lazy-load sekce se po posunu správně načtou.
- Článkové CTA: mobilně čitelné, vede na `/kontakt?service=Provozní%20řády#poptavkovy-formular`; odstraněna osamocená tečka za odkazem.
- Produkt FID: český meta description, H1 a CTA odpovídají změně; CS, EN a DE CTA vedou na správnou jazykovou kontaktní stránku a zachovávají název produktu.
- Článek z 27. 8. 2026 je po statickém buildu současně na homepage, v přehledu Poradny a v sitemap.

### Poznámka k přesnému `npm run verify`

Příkaz byl spuštěn. Lint, TypeScript a oba přímé testy prošly. Výchozí Turbopack build se v izolovaném worktree zastavil pouze proto, že lokální `node_modules` je sdílený junction vedoucí mimo kořen worktree. Následný produkční build stejného kódu přes Webpack prošel. V GitHub/Vercel prostředí se závislostmi nainstalovanými přímo v projektu je nutné před produkčním nasazením potvrdit standardní build.
