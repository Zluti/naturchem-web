### Poznámka k `npm run verify`

`npm run verify` byl spuštěn. Lint a TypeScript prošly; výchozí Turbopack build se v integračním worktree zastavil pouze proto, že `node_modules` je lokální Junction vedoucí mimo kořen worktree. Ekvivalentní produkční build příkazem Next.js s `--webpack` ve stejném worktree následně prošel. V CI/Vercelu, kde jsou závislosti nainstalované přímo v projektu, je nutné před produkčním nasazením potvrdit i standardní build.

## Produkční postup

1. Vyžádat výslovný souhlas s push, sloučením do `main` a jedním produkčním deploymentem.
2. Pushnout větev `codex/release-growth-2026-08-24` a sloučit ji přes kontrolovaný PR nebo ekvivalentní čistou integraci.
3. Povolit právě jeden Vercel deployment a ověřit jeho úspěšný standardní build.
4. Po nasazení spustit routing a URL smoke test proti `https://www.naturchem.cz` a ověřit oba článkové odkazy. Neodesílat testovací skutečnou poptávku bez samostatného souhlasu.
5. V GA4 zaregistrovat event-scoped custom dimension `lead_id`; u první skutečné poptávky porovnat ID v e-mailu a GA4.
6. Po 24 hodinách a znovu po uzavření 30denního Vercel okna zkontrolovat Active CPU, Middleware CPU, ISR reads a počet deploymentů.
